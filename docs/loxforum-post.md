**[Plugin] Rituals2Lox - Rituals Perfume Genie for Loxone (LoxBerry)**

Hi all,

I'd like to share Rituals2Lox, a LoxBerry plugin that connects Rituals Perfume Genie diffusers to the Miniserver.

- Automatic token handling for the Rituals account
- Status/control via UDP to the Miniserver
- Loxone Wizard XML generator for Virtual Inputs/Outputs
- Web UI + logging

Download / source: https://github.com/mi3k8y/rituals2lox/releases/latest
Requires LoxBerry 2.0+. Unofficial project, not affiliated with Rituals.

Feedback and bug reports welcome via GitHub issues. If it helps you, you can support further development here: https://buymeacoffee.com/jan_hajek
