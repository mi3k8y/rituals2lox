Rituals2Lox - Help

Initial Setup

  1. Enter your Rituals account email and password and save.
  2. Click Refresh Token Now - the status indicator should turn green.
  3. Enter the IP address of your Loxone Miniserver and a UDP port (default 56069), save.
  4. In Loxone Config, create a Virtual UDP Input on the same port. Add commands matching the UDP keys below.
  5. To send commands, create Virtual HTTP Output entries using the URLs shown in the integration panel.

Token Management

The Rituals API issues short-lived tokens (~50 min). Rituals2Lox refreshes automatically every 45 minutes via cron. You can also click Refresh Token Now at any time. If a refresh fails (network outage etc.), the grabber logs a warning and skips that poll cycle - the next cron run will recover automatically.

The hub parameter is the 64-character hex hash from the API response (logged by grabber on first run). This is different from the hublot (e.g. LOT119-12-A4980-022) which is a human-readable lot number.

Log files

  • grabber.log - poll results, UDP messages, hub hashes
  • token-manager.log - token fetch results and expiry info
  • sendcmd.log - command execution log
  • webui.log - web interface actions
